## What I learned

- **Writing failure cases finds real bugs.** Five were fixed on 11/15: no digest retry, provider
  error → HTTP 500, unknown source ref → HTTP 500, embedding error → HTTP 500, and the bot
  parsing error bodies as normal replies.
- **SDK defaults are not safe defaults.** OpenAI's default was 600 s plus 2 silent retries, longer
  than the bot's 120 s wait. Every timeout is now set explicitly, and worst cases add up to under 120 s.
- **Retry bad output, not slow calls.** A malformed answer may be fixed by one more try. A timeout
  just doubles the wait.
- **A citation the model made up is malformed output.** It is treated like bad JSON and never shown.
- **Test through the same path as the bot.** `bot.dispatch()` → FastAPI `TestClient` caught the bot
  showing pydantic errors, which endpoint-only tests could not see.
