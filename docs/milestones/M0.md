## Unexpected failure

- Link type: company tech blog hosted on Medium (free article, no login)
- What I expected: fetch the article text
- What happened: `status: fetch_failed`, `error: http_403`. The body is a
  Cloudflare block page (HTML), not the article. The code correctly did not
  save it as content.
- Checked: curl with our User-Agent -> 403; curl with a Chrome User-Agent -> 403.
  So the block is not based on User-Agent alone.
- Next action: treat Medium-hosted pages as a known limitation for M0. During the
  10/17 real-link run, test whether the blog's RSS feed (`/feed`) gives full text.
  Do not add browser automation.
